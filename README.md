## Implementação

O site usa HTML, CSS e JavaScript. A capa apresenta meu nome e retrato em uma composição editorial, com tipografia condensada, um detalhe em vermelho e acesso direto aos projetos. O ícone da aba usa o mesmo monograma “Mc” do cabeçalho. A navegação por âncoras conecta as seções de perfil, projetos e contato. O JavaScript atualiza o item ativo do menu conforme a rolagem. A página também oferece navegação por teclado e respeita a preferência de movimento reduzido.

## Executar localmente

Na raiz do repositório, com Python 3 instalado, execute o comando abaixo.

```sh
python3 -m http.server 8000
```

Abra <http://localhost:8000>. As fontes, imagens e o currículo são servidos junto com a página. O projeto está pronto para hospedagem estática.

## Atualizar o conteúdo

| Arquivo | Responsabilidade |
| --- | --- |
| `index.html` | Biografia, projetos, tecnologias e links de contato. A galeria é editada manualmente. |
| `style.css` | Cores, tipografia, composição da capa e layouts para diferentes telas. |
| `nav.js` | Indicação da seção ativa no menu principal. |
| `assets/` | Fontes locais, ícones, retrato, imagens dos projetos e currículo. |

Para substituir o currículo, atualize `assets/matheus-correa-curriculo.pdf`.
